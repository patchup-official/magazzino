# 🔧 Magazzino v2.0

Sistema SaaS per negozi di riparazione e vendita dispositivi.

## Deploy su GitHub + Render

Segui la guida passo dopo passo nel file `DEPLOY.md`.

## Sviluppo locale

```bash
# Backend
cd backend && npm install && node server.js

# Frontend (secondo terminale)
cd frontend && npm install && npm run dev
```

App disponibile su http://localhost:5173
